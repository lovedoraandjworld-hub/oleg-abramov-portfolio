# Олег Абрамов — портфолио

Сайты и UX/UI, 3D и анимация, фигурки под печать, графика и автоматизация. Каждое направление находится в отдельной вкладке.

Статический сайт, сборка не требуется. GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

index.html — главная; projects.js — проекты; app.js — вкладки и галереи; figurines.html — отдельная страница фигурок; assets/ — медиа и обезличенные макеты.
